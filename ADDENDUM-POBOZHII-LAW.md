# Addendum. Pobozhii's Law. Universality, boundary conditions, diminishing returns

**Author.** Egor Pobozhii
**Published.** 2026-10-15
**Addendum to.** PEHT Architecture Whitepaper v1.0.0, Volume I, vector 4 (Pobozhii's Law, D* Theorem)
**Status.** Public defensive publication, same terms as the whitepaper. The main volume is not modified. This addendum is a separate timestamped release.

The D* theorem is a special case of the classical marginal-value stopping rule. This addendum states the general rule, the family of closed forms it generates, the three boundary conditions under which each closed form is exact, and the link to diminishing returns. Nothing in the theorem's numbers changes. What changes is the proven class it lives in. The document exists to make the theorem hard to misread and hard to overclaim.

## Дополнение к Закону Побожего. Универсальность и границы

**1. Зачем это дополнение.**
Основной том вывел формулу и не описал рамку. Рамка важна не меньше формулы. Здесь три вещи.
Мастер-правило, общее для всего семейства. Три граничных условия, при которых закрытая форма
точна. Связь с убывающей отдачей, из которой растёт форма ответа. Формула и число 4 не меняются.

**2. Мастер-правило.**
Пусть b_k ожидаемая выгода k-го шага цепочки, c_k его цена, обе в одной валюте, байты шины,
секунды или джоули. Выгоды шагов складываются. Оптимальная глубина есть наибольшее k, для
которого каждый шаг j от 1 до k держит выгоду выше цены

b_j >= c_j

Это классическая маржинальная остановка. Правило велит шагать пока ожидаемая выгода шага держится
выше его цены. Все закрытые формы семейства получаются одним движением. Решаем неравенство
b_k >= c_k для конкретного вида профилей, ответ есть инверсия профиля затухания. Закон Побожего
это инверсия экспоненты при постоянной цене.

**3. Семейство закрытых форм.**
Ценность шага убывает профилем d(k), стартовая ценность V, цена шага постоянна и равна c.

1. d(k) = a^k. Беспамятная цепочка, приёмка не зависит от позиции.
   D* = floor( ln(V/c) / ln(1/a) ). Закон Побожего.
2. d(k) = exp( -λ k^β ). Растянутая экспонента, появляется память о позиции.
   D* = floor( ( ln(V/c) / λ )^(1/β) ). При β=1 строка 1, при β=2 корень из логарифма.
3. d(k) = k^(-p). Степенное затухание.
   D* = floor( (V/c)^(1/p) ). Степенной корень, логарифма нет.
4. Обе стороны движутся. Цена шага растёт множителем g, g больше единицы.
   D* = floor( ln(V/c) / ln(g/a) ). Цена складывается в знаменатель.

Вывод каждой строки занимает одну строку, покажем на второй. exp(-λk^β) = c/V, значит
λk^β = ln(V/c), значит k* = ( ln(V/c)/λ )^(1/β). Остальные так же.
Если профиль не имеет закрытой формы, правило остаётся рабочим численно. Классы перечислимы,
они исчерпываются видом затухания. Экспонента даёт логарифм. Степенной профиль даёт корень.
Растянутая экспонента занимает место между ними, а при β больше единицы даёт корень из логарифма.

**4. Три граничных условия.**
Первое, распад экспоненциальный. Формула жива там, где затухание беспамятно, каждый следующий шаг
падает на тот же множитель a. Если ценность падает степенно, оптимум растёт как корень степени,
а не как логарифм. Логарифм есть подпись экспоненты, это видно по таблице выше.
Второе, приёмка постоянна по глубине. В живой цепочке a слегка плывёт от позиции и контекста.
Строгое обобщение тогда есть произведение приёмок по шагам. Продолжай пока произведение держится
выше c/V. Одна дробь исчезает, правило остановки остаётся, появляется эффективный наклон.
У наших замеров плывучесть мала, a одно число, приближение живёт в пределах шума.
Третье, цены не плывут внутри раунда и нет дальновидности между раундами. Спекуляция исполняет
это по конструкции. Один проход цели проверяет всю цепочку, цена раунда от глубины не зависит,
шаг драфта стоит одинаково в начале и в конце. Убери условие, например заведи плату за глубину
в самой цели, и в формулу войдёт цена, зависящая от k, это уже четвёртая строка семейства.

**5. Связь с убывающей отдачей.**
Форма ответа растёт из закона убывающей отдачи. Ценность k-го шага есть a^k от потолка. Первый
шаг несёт (1-a) потолка, второй (1-a)*a, дальше по геометрии. Сумма всего хвоста после первого
шага равна a/(1-a), при a=0.531 это 1.13, то есть неоглядный хвост стоит одного шага с небольшим.
Поэтому оптимум мелкозуб и логарифмичен. Глубина обратно пропорциональна ln(1/a), удвоение
цепочки требует корня из приёмки. Числа для калибровки. Шаг в 5 процентов раунда даёт 4, шаг
в один процент даёт 7, приёмка 0.9 даёт 28, приёмка 0.3 даёт 2. Ниже порога цены честный отказ,
D* = 0.

**6. Границы притязания.**
Мастер-правило есть классический принцип равенства предельной выгоды и предельных издержек,
известный экономике и теории оптимальной остановки. Мы его не присваиваем. Притязание Закона
Побожего узкое и прежнее. Отображение спекулятивной цепочки на это правило, закрытая форма для
беспамятной приёмки, и живой замер на телефонах, a=0.531, оптимум 4. Дополнение защищает узкую
часть со всех сторон и не расширяет её. Тот же контур работает в мультипликативной сборке, где
выгода перемножается и счёт идёт в логарифмах, и с неопределённостью, где вместо отношения
берётся нижняя доверительная граница и получается правило запуска с запасом, оно уже упомянуто
в рынке срочных вычислений.
